# Trees Debugthon

沈伯洋市政 debug 松「把三千棵樹種回來」的第一階段資料探索工具。使用 **Leaflet + OpenStreetMap**，不需要 API 金鑰。這一版在本機執行，尚未部署。

## 啟動

需要 Node.js 20.19+ 或 22.12+；更新資料另外需要系統 `curl`。

```sh
npm install
npm run dev
```

開啟終端機顯示的網址，預設為 http://127.0.0.1:5173/ 。`public/data` 已附官方資料快照，不需要先更新資料。底圖和選用的 Google Fonts 字型需要網路，字型載入失敗時使用系統字型。

## 使用

- 勾選五個圖層，調整各自透明度，並用行政區篩選。
- 搜尋已勾選圖層的名稱、路段、位置或編號欄位，例如路名、公園名稱或樹種；按 Enter 定位符合的資料。這不是地址地理編碼服務。
- 地圖數字顯示目前視野與篩選條件下的紀錄筆數，跨圖層加總不等於樹木總數。
- 全市視角使用空間網格合併所有點位，不抽樣。點擊圓圈可放大；層級 17 起顯示獨立點位、人行道層級 15 起顯示面域、樹穴層級 18 起顯示面域。完全重疊的紀錄在最大縮放層級可點擊圓圈逐筆查看。
- 點擊獨立點位或面域，查看完整原始屬性；「資料說明」列出來源、快照時間、可繪製與排除筆數。
- 「符合資料」將鏡頭移至符合篩選的所有已載入紀錄；「全市視角」清除行政區與文字篩選。

## 官方資料與限制

活動來源：[市政 debug 松題目 #1](https://puma.taipei/hackathon#issue-1)。本專案**沒有模擬資料**，目前快照擷取於 **2026-10-23（臺北時間）**。

| 圖層 | 原始筆數 | 可繪製 | 來源 |
| --- | ---: | ---: | --- |
| 行道樹 | 90,358 | 90,358 | [公園處樹木分布圖](https://data.gov.tw/dataset/128274) |
| 公園樹木 | 72,011 | 72,011 | 同上，公園樹木資源 |
| 人行道樹穴／花圃 | 56,720 | 56,720 | [新工處樹穴資料](https://data.gov.tw/dataset/134908) |
| 人行道範圍 | 15,053 | 15,053 | [新工處人行道範圍圖](https://data.taipei/dataset/detail?id=715d3a83-8445-4496-b6bf-b0900538b7e7) |
| 公園、綠地與廣場 | 813 | 812 | [公園處公園基本資料](https://data.taipei/dataset/detail?id=ea732fb5-4bec-4be7-93f2-8ab91e74a6c6) |

行道樹、公園樹木及面域資料使用 `proj4` 從 TWD97 / TM2 121（EPSG:3826）轉換到 WGS84。人行道行政區的數字代碼已正規化為行政區名稱，原始屬性仍保留。公園基本資料已有經緯度，其中 1 筆缺少有效座標而排除繪製。座標驗證框為東經 121.4–121.7、北緯 24.9–25.25，這是臺北合理範圍檢查，並非行政界線空間驗證。

樹穴包括花圃，**不表示空穴**；公園位置點**不代表公園面積或邊界**。樹木點位不代表樹冠、樹蔭或存活狀態，資料集時間也不一致。目前沒有納入完整逐年移除履歷與原因、現場淨空、地下管線或可種植性調查，不應將圖層相減直接視為可種植清單。

## 更新資料

```sh
npm run data:refresh
```

`scripts/prepare-data.mjs` 使用 `curl` 從來源下載，原始檔放在忽略追蹤的 `data/raw/`；輸出 WGS84 GeoJSON 和 `public/data/manifest.json`。資料全部轉換完成後才替換輸出，下載失敗會保留上一份可用地圖快照。更新完成後重新整理網頁；若要發布，重新執行建置。只想重新轉換本機已有原始檔可用 `node scripts/prepare-data.mjs --cached`。

## 驗證與建置

```sh
npm test
npm run build
npm run preview
```

測試涵蓋 TWD97 控制點、無效座標、多層幾何轉換、12 行政區代碼、篩選、聚合不遺漏紀錄，以及全部快照筆數與範圍一致性。

本機 Chrome 可用時，先啟動開發伺服器，再執行 `node scripts/check-browser.mjs` 驗證實際互動並產生桌機與手機截圖（存放於忽略追蹤的 `test-results/`）。

建置結果在 `dist/`，可放到靜態網站主機。資料快照合計約 110 MB，按圖層延遲下載並在記憶體快取；用 RBush 索引目前視野，再以 Leaflet Canvas 繪製獨立點位與面域。正式對外服務時可再增加壓縮、向量圖磚與版本化快取。底圖服務可於 `src/main.js` 的 `L.tileLayer` 設定更換。
