02 / EXPLORE POSSIBILITIES

尋找 API 候選植物

原生身分待覆核。已知馬纓丹原生旗標與描述矛盾，暫不納入草稿。資料庫標記不等於已核實原生名錄；請對照學名與可靠來源。

尚未查詢；每次最多 12 筆，不預載整庫。不先限制植物形態；每次廣取最多 12 筆後依候選層次分組。日照／量測水分僅本機比較；海拔若提供會先篩選且可能排除未知。

03 / COMPOSE WITH CARE

自然式配植草稿

手動挑選、分層思考，不自動生成比例或株數。

缺根域深度、冠幅與現地調查：無法判定樹穴適配、密度、株距或安全。葉形分析不可用；質感與樹冠形狀不是葉形辨識。
