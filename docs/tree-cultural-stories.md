# 臺北樹木歷史文化故事資料表

臺北樹木與植物的歷史文化故事初步研究表：按樹種、特定地點與時期分筆，收錄政策、校園景觀、機構贈苗、民間捐樹、地方記憶與護樹事件。

探索性歷史文化資料，不是全市故事普查。樹種名稱保留來源用名，未統一分類鑑定；逐名稱首輪查詢另列471個原始標籤，其中468個可查名稱只有170個取得可用搜尋結果，298個受搜尋存取限制（75個僅受阻請求、223個未逐名請求），另3個名稱待釐清。未找到或受阻不代表沒有故事；不將場域歷史直接套用現存GIS個體。 使用者提供圓山植物史摘頁（印刷頁21–24）另列待查線索與補充來源，未核引註原著，不與已讀來源支持摘要混稱。
