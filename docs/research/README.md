# 樹木歷史文化研究流程

## 範圍
以「樹種 × 臺北特定地點 × 時期／事件」為一筆，不以全市樹種概括所有樹木身世。首批為探索性蒐集，不是完整樹種文化史或全市故事普查。植物學介紹若無歷史事件、政策、捐贈或地方生活脈絡，不單獨當作文化故事。

## 證據
- 每筆摘要須對應實際閱讀的來源正文；記錄標題、單位、網址、刊出日期（無則 null）、查閱日期、段落／頁碼及短摘錄。
- source-supported：來源正文支持此筆有限範圍摘要；不代表已獨立交叉查證，也不自動證明現有 GIS 樹木是史料中的個體。
- lead：研究線索，核心敘事尚待查證；不混稱已證實故事。
- 特定樹木、地點背景、植栽政策、一般文化脈絡分開標示。口述記憶、約略樹齡及單一報導須明寫限制。
- 捐土地、捐雕塑與捐樹不同；不能把公園開闢日期當作每株植樹年份。新聞轉載不當成兩個獨立證據。
- 搜尋片段、未能讀取的頁面、只有頁尾的網頁，不足以支持故事摘要。不得虛構引用、種植者、捐贈者、年代或座標。

## 資料與維護
`public/data/tree-cultural-stories.json` 是正式資料來源；線上頁 `/stories/research/index.html` 直接讀取此檔，不下載完整樹木快照。`node scripts/tree-history-data.mjs` 產生 CSV 與 `docs/tree-cultural-stories.md`；`--check` 檢查匯出是否同步。CSV 使用 UTF-8 BOM，並處理試算表公式字元。

同資料夾的分組 JSON 為研究候選與查核交接記錄；只有 parent review 合併到正式 JSON 的筆數才會出現在網站。修改內容後需重新執行結構／單元／瀏覽器驗證，依既有序列化發布流程提交與部署；不自動更新原始樹木或影像資料。

## 全原始名稱首輪（2026-10-24）
盤點現有兩個已地圖化樹木快照，共162,369筆、471個不同的trim後原始名稱標籤，不等於471個分類學物種。空白、枯木與烏?待辨名；其餘468個名稱保留原文，不靜默整併同物異名。

目前170個名稱取得可用搜尋結果；75個只有受阻請求，223個尚未逐名請求（共享搜尋存取受阻）。實際發出320次請求涉及245個名稱，不能把產生查詢網址、驗證頁、無關結果或受阻回應算作完成查詢。298個待補項目仍開放，不代表沒有歷史故事。搜尋API未配置，替代搜尋管道遇到驗證／限流；恢復可用搜尋服務後需補查。

盤點：scripts/tree-history-inventory.mjs --check；原始資料SHA、名稱ID與數量在species-inventory.json。逐名請求紀錄與候選在species-round1/。18筆新增故事由另一輪逐URL正文核對，調整4筆名稱或摘錄；source-review-compact.json保留擷取時間、正文雜湊、短摘錄比對與判定。完整外部正文與搜尋回應只留本機研究暫存，不隨站點發布，也不當成網站資料。

使用者提供PDF採provided-document來源型別，保留文件ID、repo文件路徑、印刷頁與PDF頁；沒有公開來源網址時不虛構連結。附件可支持「該研究摘頁提出此說法」，不能冒稱已讀其所有引註原文；待查核心主張標lead，作者詮釋與歷史事實分開。PDF原檔留repo研究文件，非公開網站下載資產。
