# Village ecology game: feasibility audit
Checked 2026-10-23. Research only; no dashboard implemented or deployed.

## Six indicators
- Green coverage: not computable from tree points. Existing managed-tree density/sidewalk proximity are usable proxies only with different labels. Taipei catalogue searches for 綠覆/綠覆率 found no suitable village dataset in this audit, not proof none exists. Citywide annual green-resource statistics cannot be split into villages: https://data.taipei/dataset/detail?id=c9038665-c084-4bd9-a395-15c99bf59cdf . True coverage needs licensed dated vegetation polygons or validated imagery analysis. Imagery downloads remain paused.
- Protected trees: official Culture Bureau CSV downloaded successfully: 3,874 raw rows, UTF-8 BOM, fields include ID, scientific name, DBH/circumference metres, lon/lat. Coordinates nonempty in all rows, but numeric validity and unique IDs not yet audited. https://data.taipei/dataset/detail?id=d9d1140b-c2c3-405f-8dd1-7b87b00f6f53 ; resource rid=a7c2db0d-8b6e-42b2-bdcc-ae69a6797e1d . File updated 2026-03-23 while metadata coverage ends 2023-04-11; do not promise current legal completeness. Potential big trees can be measured-size screening candidates using existing Diameter/TreeHeight/SurveyDate after unit/date audit, never inferred legal designation.
- Plant richness: existing 162,369 street/park tree records and 456 village boundaries support source-name category richness, Shannon and dominance, NOT full plant species richness. https://data.gov.tw/dataset/128274 . Reconcile taxonomy and sampling before ecological comparisons. River trees add scientific names/DBH/crown projection, but are one-off 2016 records, not current citywide coverage: https://data.taipei/dataset/detail?id=34800b67-b5a5-4ce9-9892-eb0945b82644 . Summed crown areas are not union canopy coverage.
- Native share: feasible with curated names-to-TaiCOL mapping. Public sample tested: https://api.taicol.tw/v2/taxon?scientific_name=Ficus%20microcarpa returns accepted t0046305 and alien_type=native. Docs https://taicol.tw/zh-hant/api ; policy https://taicol.tw/zh-hant/policy (text generally CC BY 4.0). Show native/identified records plus identified/all records. Unknown is not non-native; Taiwan native is not proof of local Taipei provenance. Cache unique taxa, manually resolve names/cultivars.
- Bird/insect diversity: feasible as observed-species atlas, not ecological ranking. TBN public v2.6 https://www.tbn.org.tw/data/api/v26/occurrence supports coordinates/date/taxon/uncertainty/license and spatial filters. Worker tested Taipei 2025 birds 314,159 records and butterflies 5,206, not species or individuals. Example https://www.tbn.org.tw/api/v26/occurrence?eventPlaceAdminarea=%E8%87%BA%E5%8C%97&taxonGroup=birds&year=2025&limit=1 . One sample had 1,182 m uncertainty: cannot force into a village. Use observation dates, consistent periods, recording effort and precision filtering. Groups butterflies/moths/beetles/dragonflies/otherinsects, not insects. Alternative APIs https://techdocs.gbif.org/en/openapi/ and https://api.inaturalist.org/v1/docs/ ; duplicate observations across aggregators must not be summed, photo licenses differ, some records are CC BY-NC. No fixed numerical rate guarantee verified: cache, paginate, honor 429. Taipei river bird CSV is one-off 2012–2015 despite 2026 file update: https://data.taipei/dataset/detail?id=8eea1e09-055b-4b3d-9472-b96744b1727e . Historical reference only.
- Convenience: immediately feasible from clean-bin coordinates; 661 raw Big5 rows downloaded, district/address/lon/lat/notes. https://data.gov.tw/dataset/121355 ; https://data.taipei/dataset/detail?id=a835f3ba-7f50-4b0d-91a6-9df128632d1c . Main resource rid=267d550f-c6ec-46e0-b8af-fd5a464eb098 . Separate tourist subset may overlap. These are pedestrian litter bins, not household-waste collection or cleanliness. Use counts plus proximity along sampled sidewalks; straight-line buffers are not walking routes. Include facilities across village boundaries.

## Other verified official sources
- Public toilets: 1,537 raw UTF-8 BOM rows downloaded; coordinates, stall counts, accessible/family stalls, quality classes. https://data.taipei/dataset/detail?id=ca205b54-a06f-4d84-894c-d6ab5079ce79 ; rid=9e0e6ad4-b9f9-4810-8551-0cffd1b915b3 . Place count != stall count; no always-open assumption.
- Public drinking water: 144 raw Big5 rows downloaded; coordinates, machine count and opening hours. https://data.taipei/dataset/detail?id=f158e1bc-8400-44c2-a93a-e09361ddb7f5 ; rid=52538305-ed23-490c-8f67-3efff2d777c3 . Direct-drinking fountains are separate: https://data.taipei/dataset/detail?id=155999f2-3c5d-486b-af58-d7f4c0b0a4c9 (linked metadata, not downloaded).
- Cooling refuges: public subset 720 raw Big5 rows downloaded; coordinates, opening hours, indoor/outdoor, seats, AC, water and accessibility. https://data.taipei/dataset/detail?id=a98a3e0e-a36f-43fa-82f8-b09a3011a47a ; rid=ae7e5986-859d-4294-b289-7c1b2e7c23f1 . Other subsets overlap. Measures access, not ambient temperature.
- Village age/population: monthly area codes, sex/age counts, suitable context and per-1,000-resident denominator. https://data.taipei/dataset/detail?id=a6394e3f-3514-4542-87bd-de4310a40db3 . Metadata verified; full 19.86 MB resource not downloaded. Align boundary versions; residents != daytime visitors.
All resource downloads use https://data.taipei/api/frontstage/tpeod/dataset/resource.download?rid=RESOURCE_ID . Raw row counts are not validated unique/current facilities.
Hackathon https://puma.taipei/hackathon original HTML confirms tree/tree-pit/sidewalk/park, clean-bin, MRT traffic and bus stop links. TDX requires application/key. Most municipal amenities are snapshots, not real-time APIs. Preserve each source's actual license/attribution.

## Product/scoring recommendation
MVP: managed-tree record density, managed-tree name diversity, official protected-tree records, litter-bin/toilet/water/cooling accessibility. Native share follows taxonomy mapping; bird/insect atlas follows precision/license checks; true green coverage pending.
Show raw values, denominator, date, confidence and missingness before any 0–100 score. Unknown != zero. Relative percentiles must identify reference population/version and distinguish mountain vs dense urban conditions. No arbitrary thresholds called official. Separate player contributions/verified missions from environmental condition scores. Few observations prompt observation missions, not claims of poor ecology. Tree gaps prompt field audit, not planting permission. Do not incentivize disturbing wildlife, publishing sensitive coordinates, trespass or removing non-native trees. Uploads need consent/moderation/storage/auth design.
